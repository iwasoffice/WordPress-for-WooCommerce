# Setup

## Required WordPress components

- WordPress
- WooCommerce
- IWAS Commerce theme
- IWAS Commerce Core plugin
- Paystack WooCommerce extension
- CJdropshipping WooCommerce connection

## Recommended WooCommerce settings

- Currency: USD for the US-first launch.
- Guest checkout: enabled unless operational requirements change.
- HPOS: enable after confirming every installed extension is compatible.
- Shipping zones: United States first; do not expose destinations that the chosen suppliers cannot serve reliably.
- Inventory: enable stock management where supplier synchronisation supports it.

## Pages

WooCommerce should create Cart, Checkout and My Account. Create additional WordPress pages for Shipping, Returns, Privacy, Terms, Contact, FAQ and Offline.

## Store title

The customer-facing brand uses WordPress Settings -> General -> Site Title. The theme deliberately does not hard-code a final brand name.
