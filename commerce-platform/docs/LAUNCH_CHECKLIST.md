# Launch checklist

- [ ] Final brand and domain verified before public use.
- [ ] Samples ordered for every launch product family.
- [ ] Supplier warehouse, handling time and shipping destination confirmed.
- [ ] Return address/process confirmed.
- [ ] Paystack live account approved and international acceptance confirmed where needed.
- [ ] Real checkout completed with a low-value transaction.
- [ ] WooCommerce order reaches supplier workflow.
- [ ] Supplier tracking returns to the order.
- [ ] Refund tested.
- [ ] Failed-payment behaviour tested.
- [ ] Out-of-stock behaviour tested.
- [ ] Mobile checkout tested on Android and iPhone browsers.
- [ ] Light, dark and system appearance tested.
- [ ] Privacy, returns, shipping and terms reviewed for the real business.
- [ ] Analytics consent configuration reviewed for target markets.
- [ ] Backups and restore procedure tested.
